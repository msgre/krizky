# 2026-08-15-01 — Plugin krizky-map

## Cíl

Nový plugin `krizky-map` pro tři use cases mapy nad Leaflet: detail místa, kategorie (nad výpisem) a samostatná mapa. Kompatibilní s `krizky-filters` — reaguje na filter event a překreslí piny.

## Zásadní rozhodnutí (odsouhlaseno v předchozí konverzaci)

- **Vlastní geojson per stránka** (`/maps/<stem>.geojson`), loose coupling s filter pluginem přes runtime event.
- **Ikona kategorie**: kapka s SVG symbolem uvnitř (existující `i-kategorie-{slug}` sprite projektu). Opt-in přes `markers.category_field`; bez configu univerzální marker.
- **SSR-precomputed bounding box** předaný v `data-map-bounds` — žádné „skoky" po fetchi geojson. Filter update = jen piny, view se nemění.
- **Bez JS**: `<noscript>` fallback ve všech makrech.
- **Leaflet knihovny**: uživatel si stáhne do `assets/leaflet/`, plugin nekopíruje 150 kB třetí strany.
- **Deep link `?id=slug&zoom=N`** vypuštěn (byl v starém kódu, ale nefunkční na produkci).
- **`site.map:`** = globální projekt-wide invariants (tile, marker, cluster, mask, overlays, leaflet URLs).
- **`pages.<X>.map:`** = jen dva klíče: `map: true` (opt-in) a `map: {fields: [...]}` (override properties v geojson).
- **Mode chování** (cluster on/off, popup, panel) určeno voláním makra, ne configem.

## Hooky

| Hook | Kdy | Co dělá |
|---|---|---|
| `prepare_jinja2_environment` | 1× per build | plugin templates do loaderu; globals `map_config`, `map_bounds` (SSR bounds compute) |
| `inject_head` | per stránka (pouze `map:` truthy) | tile preconnect + `<link>` Leaflet.css + markercluster.css + map.css |
| `inject_body_end` | per stránka (pouze `map:` truthy) | `<script>` Leaflet + markercluster + map.js (defer) |
| `after_page_written` | per stránka | pro non-detail s `map:` → `/maps/<stem>.geojson`; assety + mask + overlays kopírované jednou per output |

## API v šablonách

**`map_detail(record, height="360px", category=none, zoom=15, lat_field="latitude", lng_field="longitude", name_field="nazev")`** — jeden pin, popup s název + kategorie, bez clusteru.

**`map_list(records, src=none, height="360px", cluster=true)`** — cluster mapa nad výpisem, popup s název + kategorie + odkaz „Otevřít detail", automatická integrace s filter eventem.

**`map_full(records, src=none, height="calc(100vh - 60px)", cluster=true, locate_button=true, panel_label="Mapa míst", panel_hint="…")`** — layout `<div>` (mapa) + `<aside>` (side panel: thumbnail, název, kategorie, odkaz). Panel se plní po kliknutí na pin, mobilní scrollIntoView. Locate button přes `navigator.geolocation`.

## Data flow

1. Uživatel do `pages.<X>` doplní `map: true` nebo `map: {fields: [...]}`.
2. Při buildu `after_page_written` (pro non-detail) zavolá `build_feature_collection(records, fields, lat_field, lng_field)` → `write_geojson(fc, output_dir, stem)`.
3. Šablona volá makro → vygeneruje `<div class="krizky-map" data-map-mode data-map-src data-map-bounds data-map-config>`.
4. `map.js` scanne `[data-map-mode]`, spustí Leaflet init podle režimu.
5. `list` a `full` fetchují geojson, cluster (pokud `L.markerClusterGroup` existuje), stavějí markery.
6. Poslech `krizky-filters:update` (pokud aktivní): `event.detail.filteredRecords` → set slugů → filtruje features.
7. `detail` má vše v `data-*` atributech (jeden pin, žádný fetch).

## Integrace s krizky-filters

Coupling **jen na runtime úrovni** — plugin nemá Python závislost na filters. Když filters není nainstalovaný, mapa jednoduše nedostane event a zobrazí všechny features. Pokud je nainstalovaný, filters emituje `krizky-filters:update` s `detail.filteredRecords`; mapa vezme `record.slug` a přidá/odebere marker z layer group.

## Bounding box

- **SSR** (`build_feature_collection`) vrací `bbox: [minLng, minLat, maxLng, maxLat]` (GeoJSON spec).
- **Šablona** volá `map_bounds(records)` (Jinja2 global) → Leaflet formát `[[minLat, minLng], [maxLat, maxLng]]` → `data-map-bounds` JSON atribut.
- **JS** `fitBounds(bounds, {padding: [30, 30], maxZoom: 12})` při init — mapa začíná ve správném view.
- **Filter update**: view se **nemění**, jen piny (uživatelova preference).
- **0/1 records**: fallback na `default_center` + `default_zoom`.

## Ikony marker

`L.divIcon` s inline HTML:

```html
<div class="k-marker-wrap" style="--marker-color:#850000">
  <span class="k-marker-body"></span>
  <svg class="k-marker-icon"><use href="#i-kategorie-kriz"/></svg>
</div>
```

- `shape: drop` — kapka (border-radius 50% 50% 50% 0, rotate(-45deg)).
- `shape: circle` — kruh.
- Ikona uvnitř: pokud `markers.category_field` je nastavené, dohledá `#{icon_prefix}{value}`. Bez configu / bez category → `fallback_icon`. Bez toho → jen kapka bez ikony.

## Konfigurace

Aplikováno na `temp/config.yaml`:

```yaml
site:
  map:
    tile: {provider: osm, max_zoom: 19}
    markers: {shape: drop, color: '#850000', size: 32,
              category_field: kategorie_slug, icon_prefix: i-kategorie-, fallback_icon: i-mark}
    cluster: {max_radius: 50, disable_at_zoom: 14}
    mask: {polygon: ./data/valassko.geojson, fill_color: '#000000', fill_opacity: 0.3, blur: 2}
    default_center: [49.4, 17.95]
    default_zoom: 9
    leaflet: {js: /assets/leaflet/leaflet.js, css: /assets/leaflet/leaflet.css}
    markercluster: {js: /assets/leaflet/leaflet.markercluster.js, css: /assets/leaflet/MarkerCluster.css}

pages:
  detail:
    detail: true
    map: true
  vsechna_mista:
    map: {fields: [nazev, umisteni, kategorie_slug, thumbnail_url]}
  mapa:
    paginate: false
    map: {fields: [nazev, umisteni, kategorie_slug, thumbnail_url]}
```

## Technické poznámky

- **Config_dir v after_page_written**: hook v core `config_dir` nepředává. Plugin ho uloží na instanci v `prepare_jinja2_environment` a používá v `after_page_written` pro resolve cest k mask/overlay souborům. Alternativou by bylo rozšířit hookspec, ale to bylo považováno za zbytečnou core change pro jeden edge case.
- **`_public_url` split**: URL pro mask + overlays se registruje v `prepare_jinja2_environment` (`_register_data_urls`), aby `map_config` global obsahoval `mask.url` a `overlays[].url` už při renderu první stránky. Reálná kopie souborů zůstává v `after_page_written`, kde je dostupný `output_dir`. Test `test_register_data_urls_before_first_render` to explicitně ověřuje.
- **Cross-plugin**: coupling s filters je pouze runtime přes CustomEvent. Filter i mapa fungují samostatně.
- **Marker anchor**: kapka `[size/2, size]` (spodek), kruh `[size/2, size/2]` (střed). Popup anchor `[0, -size]`.
